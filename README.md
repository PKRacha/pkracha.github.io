# Prashanth R - Personal Website

A modern, responsive personal website for Prashanth R, Principal Data Analytics Engineer. Built with HTML, CSS, and JavaScript, featuring a clean design inspired by modern portfolio templates.

## Features

- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Modern UI**: Clean, professional design with smooth animations
- **Navigation**: Easy navigation between different sections (Home, Blog, Projects, Resume)
- **Contact Information**: Integrated contact details and social media links
- **Mobile Menu**: Hamburger menu for mobile devices
- **Smooth Scrolling**: Enhanced user experience with smooth page transitions
- **Component System**: Modular header and footer components for easy maintenance
- **GitHub Pages Compatible**: Static site architecture that works perfectly with GitHub Pages

## Pages

- **Home** (`index.html`) - Main landing page with introduction and call-to-action buttons
- **Blog** (`blog.html`) - Articles and insights (to be created)
- **Projects** (`projects.html`) - Portfolio of projects (to be created)
- **Resume** (`resume.html`) - Professional experience and skills (to be created)

## Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/pkracha/pkracha.github.io.git
   cd pkracha.github.io
   ```

2. Open `index.html` in your web browser to view the website locally.

3. For GitHub Pages deployment, push the changes to the main branch and the site will be available at `https://pkracha.github.io`.

## Customization

### Personal Information
Update the following in `index.html`:
- Name and title in the header
- About me description
- Contact information in the footer
- Social media links

### Profile Photo
- Add your profile photo as `images/profile.jpg`
- The image will be automatically cropped to a circle and sized appropriately
- Recommended size: 600x600 pixels or larger for best quality

### Styling
Modify `styles.css` to customize:
- Colors (primary: #ff6b35, secondary: #dc3545)
- Typography (Inter font family)
- Layout and spacing
- Responsive breakpoints

### Functionality
Edit `script.js` to add or modify:
- Mobile menu behavior
- Smooth scrolling
- Animations and interactions

### Component System
The website uses a modular component system:
- `components/header.html` - Reusable header component
- `components/footer.html` - Reusable footer component
- `js/components.js` - Component loader for GitHub Pages compatibility
- Each page only needs to include the main content between header and footer placeholders
